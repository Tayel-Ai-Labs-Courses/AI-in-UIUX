# AI in UI/UX

Course repository — TAYEL AI LABS.

Projects live in their own numbered folder. Everything a student needs for a
project is inside that folder: the brief, the rubric, the resources, and the
template they copy to start.

| Project | What it is | Status |
|---|---|---|
| [final-project-1](final-project-1) | Design the interface for an AI automation tool (n8n) | Open |

## For students

Go into the project folder and read its `README.md` first. Then
`brief/01-brief.md`. Do not start drawing before you have read the rubric —
it is not weighted the way you expect.

Your work goes in `<project>/submissions/your-name/`. Only in there.

## For instructors

Each project folder is self-contained. To add a second project, copy the
structure of `final-project-1` and renumber it.

## Note on visibility

This repository is public. Student submissions pushed here are visible to
anyone. Do not commit personal information, client work under NDA, or anything
a student has not agreed to publish.
